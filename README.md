## 🔹 Demo: Local Sensitivity Analysis (Executable)

A standalone Windows executable is available for users who want to run
the sensitivity analysis without installing Python.

### Download
- Go to the **Releases** page:
  https://github.com/Hasan-024/Uncertainty-aware-inverse-design-of-alloys/releases)
- Download `Alloy718_Local_Sensitivity_Demo.exe`

### Usage
1. Double-click the executable
2. Enter a base composition (wt.%)
3. Enter expected variations in composition
4. View predicted yield strength and sensitivity results

### Notes
- The executable is built using PyInstaller
- All model files are bundled internally
